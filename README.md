# ИСТОК — калькулятор потерь на поиске информации

**[Открыть калькулятор →](https://ssazurov.github.io/istok-calculator/)**

Небольшой веб-калькулятор: сколько времени и денег компания теряет,
когда сотрудники не могут быстро найти нужный документ, регламент или
ответ на вопрос — и сколько можно сэкономить, если поиск станет быстрее.

## Как это работает

Вводите:
- сколько минут в день сотрудник в среднем тратит на поиск информации;
- сколько сотрудников работает за компьютером;
- сколько рабочих дней в месяце;
- стоимость часа работы — по зарплате или напрямую ставкой.

Калькулятор считает:
- сколько часов и денег компания теряет на поиске сейчас;
- сколько останется потерь, если сократить время поиска (например, с
  помощью RAG-системы, которая ищет ответы по внутренним документам) —
  насколько сократится время поиска, задаётся отдельным параметром.

Всё считается на лету в браузере, ничего никуда не отправляется.

## Технологии

Один статический файл: HTML + CSS + vanilla JS, без сборки и зависимостей.
Хостится на GitHub Pages.

## Локальный запуск

Просто открыть `index.html` в браузере — сервер не нужен.
